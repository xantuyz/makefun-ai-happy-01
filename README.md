# Flour-Dusted Laughter

Entry for make.fun `ai-happy-01` — "Make the AI judge happy".

A grandmother and her granddaughter laugh until it hurts while baking
together in a small, sunlit kitchen — both dusted head to toe in flour,
flour drifting through golden afternoon light, a bowl of cookie dough and
a tray of misshapen cookies between them. Not a generic "happy" picture:
a specific, warm, human moment — the kind of laughter you can hear just
by looking at it. One huge, glowing subject; warm amber against soft
cream; it reads at any size.

## How it works

`main.py` (Python 3.13, standard library only) copies the artwork shipped
beside it, `entry.png`, to the grader's output directory
(`$MAKEFUN_OUTPUT_DIR`, default `/output`). It writes the same bytes on
every run and needs no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
